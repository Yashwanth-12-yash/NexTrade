# NexTrade  
### AI-Powered Full Stack E-Commerce Platform

NexTrade is a modern full-stack e-commerce web application inspired by leading online shopping platforms like Flipkart and Amazon.

The platform delivers a complete digital shopping experience with secure authentication, intelligent product browsing, order management, wishlist tracking, admin controls, and AI-powered shopping assistance.

---

## Live Project Overview

NexTrade simulates a real-world scalable e-commerce ecosystem with both customer-facing and administrative functionalities.

It is designed to demonstrate full-stack development skills, database integration, modern UI design, and intelligent user interaction systems.

## Installation & Setup

### Clone Repository

```bash
git clone https://github.com/Yashwanth-12-yash/NexTrade.git
```

---

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

Frontend runs on:

```text
http://localhost:3000
```

---

### Backend Setup

```bash
cd backend
python manage.py runserver
```

Backend runs on:

```text
http://127.0.0.1:8000
```

---

## Database Configuration

Configure MySQL database:

```sql
CREATE DATABASE nextrade;
```

Update Django database settings accordingly.
